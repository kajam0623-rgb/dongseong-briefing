공명
제갈량클로드 코드
클로드 코드를 부리는 법

확인하지 않고 "됐다"고 말하는 습관부터 끊으십시오.

  1. 끝났다는 기준을 먼저 정하게 하라. 일 시키실 때 고치기 전에, 고쳐졌다는 걸 무엇으로 확인할지 먼저 말해라 한 줄이면 됩니다. 반나절을 아낍니다.
  2. "다 됐습니다"에는 증거를 물으십시오. "무엇을 실행해서 확인했느냐" 한마디면 충분합니다. 빌드 통과는 확인이 아닙니다.
  3. 0%·100% 같은 반듯한 숫자를 의심하십시오. 게이트 0건 통과에 한 번 속으셨습니다. 집계 말고 원본 한 줄을 여십시오.

왜 이것이 급한가

전하의 기록에 같은 상처가 세 번 남아 있습니다. 이안치과 게이트에서 포트를 확인치 않아 남의 병원을 검사하고 0건 통과라 기뻐하신 일, 당신의치과에서 site.css?v= 를 하드코딩해 두고 바뀐 줄 아셨던 일, 화면이 뜨는 것을 보고 기능이 도는 줄 아셨던 일입니다. 세 번 다 원인이 같습니다. 본 것과 확인한 것을 구별하지 않으셨습니다.

병법에서는 이를 척후의 실패라 합니다. 척후가 "적진에 불빛이 있습니다" 하면 본 것이고, "적 본대가 저기 있습니다" 하면 판단입니다. 둘을 섞어 보고하는 척후는 군을 잃습니다.

진짜 확인이란

셋 중 하나여야 합니다. 실제로 실행해 결과를 눈으로 읽었거나, 저장된 값을 다시 꺼내 읽었거나, 화면을 눌러보고 반응을 봤거나. "코드를 작성했습니다"나 "빌드가 통과했습니다"는 코드가 깨지지 않았다는 뜻일 뿐, 기능이 돈다는 뜻이 아닙니다.

오늘은 이 하나만 몸에 붙이십시오. 나머지 기술은 다음 브리핑에서 하나씩 아뢰겠습니다.

오늘의 군령 dental-site-kit 의 킷 공용 파일 열 개(build.py 와 build/ 아래)를 한 덩이로 커밋하십시오. 코드는 더 고치지 마십시오. 이미 고쳐놓은 것을 묶기만 하면 됩니다. 다섯 시각이면 끝납니다. 내일 신이 git -C dental-site-kit log -1 로 확인하겠습니다.

전하의 사업과 삶

곳간을 막는 것은 코드가 아니라 남의 회신입니다.

  1. 이안치과 원장께 확답 여덟 갈래를 한 통에 묶어 보내십시오. 증례 수 근거·++ 표기·네이버 예약 주소·토요일 격주 휴무·수가표 세 줄·후기 넉 장 게재 승인까지, 따로 묻지 말고 한 장에 담아 오늘 넘기십시오.
  2. 기다리는 동안 dental-site-kit 미커밋 104건을 묶으십시오. 이건 누구의 답도 필요 없습니다. 전하 손만 움직이면 끝납니다.
  3. dental-geo-v2 는 이번 달 재우십시오. 4월 15일이 마지막 커밋입니다. 버리는 게 아니라 미루는 것이니, STATUS.md 한 장만 남기면 됩니다.

아침에 드린 말씀을 바로잡습니다

아침에 "이레 동안 다섯 폴더 모두 수정 0건"이라 아뢴 것은 틀렸습니다. 신이 폴더를 덜 봤습니다. 다시 세어보니 9월 6일 dental-site-kit 에 연세하늘치과 납품 커밋이 있고, 9월 7일 밤 열시에는 이안치과 wp-package 를 다시 만드셨으며, 9월 8일 아침에는 동네보살 원고가 나갔습니다. 전하의 손은 멈춘 적이 없습니다. 멈춘 것은 dental-geo-v2 하나뿐입니다.

왜 회신이 곳간을 막는가

후기 넉 장은 의료법 거름망까지 통과시켜 폴더에 넣어두셨는데, 게재 승인이 없어 화면에 못 올라갑니다. 만들어놓고 못 쓰는 것이 가장 아깝습니다. 여덟 갈래를 한 통에 묶는 까닭도 이것입니다. 한 번에 물으면 한 번에 답이 옵니다. 나눠 물으면 여덟 번 기다립니다.
